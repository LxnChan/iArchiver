发布前填写支持邮箱和公开页面地址。不要把占位内容直接提交 App Store。

## 系统“文件”无法解压

失败原因可能是文件名编码、加密方式、压缩算法、缺卷、文件损坏、云端文件未下载或可用空间不足。

1. 将归档导入 iArchiver。
2. 旧 Windows ZIP 名称乱码时，打开“文件名编码”，先查看样本，再选择 GB18030/GBK、Big5 或 CP932。
3. 加密包需要正确密码。商店版不包含专用加密 RAR 解码器；普通 AES ZIP 和加密 7z 按该版能力处理。
4. 分卷使用“打开压缩分卷”，一次选择完整且有序的一组。不要自行把 RAR/ZIP 原生分卷当成普通字节切片拼接。
5. 如需更方便与系统工具交换，可按正确编码“重新打包”为普通 ZIP；若选择 AES 加密，接收方仍需支持该加密方法。

编码选择只解释名称，不转码文件内容。自动猜测可能出错；错误 UTF-8 标志、不同头记录冲突和损坏数据不保证能修复。

## 文件保存与重名

导入和解压保留原始文件，结果存于应用目录。使用结果栏“保存到文件夹”选择导出位置。设置中的重名策略可选择保留两者、跳过或替换；替换针对整个同名项目，包括文件夹内容。

## ISO 与 RAR 边界

ISO 支持 ISO9660 及底层已支持的扩展，不挂载、不运行内容、不解密受保护光盘；UDF-only 镜像不支持。商店版 ISO 只读，侧载版额外提供 ISO9660 创建。两个版本均不创建 RAR。

## 取消、空间和后台

可在进度栏或任务列表取消。解压/预览与重打包可能需要额外临时空间，固实包选择提取可能需要先解码前面的内容。系统可暂停或终止后台工作；被终止的任务需要重新发起。
