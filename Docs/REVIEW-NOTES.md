# App Store 审核说明草稿

应用：iArchiver。构建：App Store。商业模式：付费下载，无 IAP、订阅、账号、广告和统计服务。

应用在本机浏览、创建和解压压缩包。通过系统文档选择器获得用户明确选择的文件/文件夹，复制到应用目录处理。导出使用用户选择的目录及文件协调，不访问任意设备路径。

演示步骤：

1. 用“导入”打开普通 ZIP；选择文件查看图片/音频预览，或点击“全部解压”。
2. 导入 `Legacy-GB18030.zip`，打开“文件名编码”，选择 GB18030 并应用，查看中文名称。
3. 打开样本 AES ZIP 或 7z。演示密码为 `iArchiver-demo-2026`，只用于公开测试样本。
4. 在本地目录点“选择”，选中文件后“压缩”；选择 ZIP 或 7z，可设置新密码。
5. 在压缩包中使用“重新打包”，生成经过完整解码校验的新副本。原包保留。
6. iPad / Duo 宽窗口左侧预览、右侧列表；窄窗口点文件打开预览。Duo 桌面姿态可能改为上下两个面板。

商店构建支持 ZIP、7z、TAR、TAR.GZ、GZ 的创建与读取，以及 libarchive 支持的 RAR/RAR5 基础读取和 ISO9660 读取。商店不包含专用 UnRAR 组件、不创建 RAR 或 ISO，不存在隐藏功能、审核状态识别或远程开启开关。独立侧载构建的功能不会在商店版解锁。

密码在内存中处理。文件不上传，工作目录排除备份并有系统保护。后台模式仅用于用户发起的文件任务，按系统授予情况使用公开的 continued processing API；无授权时使用有限后台时间并在到期取消，不用于常驻扫描。
